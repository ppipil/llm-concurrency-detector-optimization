# Reports

This directory is reserved for the Interim Report, Final Report, figures, and tables derived from verified project evidence.

Use `reports/interim/` for Interim drafts and supporting material. Draft outlines and prose may be versioned, but generated office-document exports and large figures should be reviewed before commit.

Reports must use the terminology, research questions, baselines, and metrics frozen in `RESEARCH_PLAN.md v2`. They must distinguish:

- hypotheses from measured findings;
- official SWE-efficiency reference values from Native-Windows measurements;
- profiler observations from unprofiled benchmark results;
- Agent-generated claims from evaluator-verified outcomes;
- current research from historical/superseded detector work.

Do not report placeholder examples, static feasibility estimates, or unexecuted commands as experimental results.
